#  Week 2 Learning Log: API Foundations & JSON Structure

This week, I am transitioning from general writing mechanics into technical API documentation. My goal is to understand how software applications communicate and how to document those connection points clearly.

##  Key Concepts Mastered

###  REST API Anatomy (Day 9)
I broke down the fundamental anatomy of a REST API using Tom Johnson's *I Rather Be Writing* curriculum. 
* **Base URL / Host:** The root address of the API (e.g., `https://api.github.com`).
* **Endpoints / Paths:** The specific destination paths that target unique data (e.g., `/users` or `/repos`).
* **Resources:** The actual data object being requested or manipulated.

###  HTTP Verbs & Headers (Day 10)
* Mapped CRUD actions to standard HTTP methods (`GET`, `POST`, `PUT`, `DELETE`).
* Studied request headers and Bearer token authentication structures.

###  JSON Parsing & Schemas (Day 11)

###  Response Status Codes (Day 12)

* Documented troubleshooting steps for `400 Bad Request` vs `401 Unauthorized`.
