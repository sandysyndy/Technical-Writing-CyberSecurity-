# Week 3 Learning Log: Hands-on API Testing & Postman Workflows

This week, I moved from theoretical API concepts into hands-on testing, request execution, and workspace organization using Postman.

## Key Concepts & Hands-on Milestones

### Sending GET Requests & Inspecting Headers 
* Executed live `GET` requests against public endpoints using Postman.
* Interrogated response headers to verify server metadata, `Content-Type: application/json`, and response latency.

### Building & Testing POST Payloads 
* Constructed raw JSON body payloads to simulate resource creation on remote servers.
* Validated server response payloads and verified `201 Created` status codes.

### Workspace Collections & Documentation Assets 
* Organized individual endpoints into structured Postman Workspace Collections.
* Captured clean, uncropped UI screenshots of verified JSON responses to embed in developer guides.

### Multi-API Tool Consolidation 
* Executed requests across three distinct public APIs (JSONPlaceholder, OpenWeatherMap, Petstore) from memory without relying on interface prompts.
